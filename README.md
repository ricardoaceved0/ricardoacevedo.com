# ricardoacevedo.com

Personal site for Ricardo Acevedo. Static HTML/CSS/JS built on the candycode design system, with scroll-driven animation.

## Run locally

```bash
python -m http.server 5173
```

Then open http://localhost:5173.

## Structure

- `index.html` – page and sections
- `styles.css` – design tokens and styles
- `script.js` – starfield, scroll reveals, scroll-driven hero and work rail
- `fonts/` – Sohne, Heldane, Berkeley
